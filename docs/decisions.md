- 2026-10-06: 점 그래픽은 canvas로 직접 그림(js/common.js의 SHAPES). 이미지 파일 없이 크기 조절에 대응.
- 2026-10-06: products.js → data.js로 변경하고 매거진 글 목록(ARTICLES)도 함께 관리(모바일 메뉴에서도 사용).

- 2026-10-06: 적립·선물하기·찜·공유·구매평·Q&A는 화면만 두고 누르면 "준비 중" 안내.
